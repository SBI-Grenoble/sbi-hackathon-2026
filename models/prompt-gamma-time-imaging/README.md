# Pavel Kavrigin — Prompt-Gamma Time Imaging

## Short description
Medical imaging technique based on a detection of prompt-gammas emitted during dose delivery in radiotherapy. Data is recorded via an array of detectors placed around a patient. The recorded data are time-of-flight values for the detected prompt-gammas. 

## Parameters of interest
- 1 to 3 parameters in a simplifed problem (verifying dose delivery range and/or transverse beam position); possibly >50 parameters in a more complicated problem (radiography). 

## Simulator output
- Array of time-of-flight values and corresponding detector numbers. 

## SBI / inference approach
- Trial-based data inference with embedding networks.
