# Models proposed by the SBI Hackathon participants

The list below repertoriates the different models proposed by the participants of the SBI Hackathon 2026. Each model has its own folder containing code, references, slides and whatever might be useful.

- [Vincent Garot — Sequence alignments from Birth-Death trees](/models/sequence-alignments/)
- [Sylvain Doute — Analytic multi-stage simulator for planetary remote sensing (photometric models)](/models/planetary-remote-sensing-photometric/)
- [Manolis Perrot — 1D PDE / EDMF model for boundary-layer turbulence](/models/edmf-boundary-layer-turbulence/)
- [Gabriel Mouttapa — Tunax: differentiable vertical ocean physics calibration](/models/tunax-vertical-ocean-physics/)
- [Louis Lesaulnier — LISA MBHB inference with 3-channel TDI time series](/models/lisa-mbhb-tdi-timeseries/)
- [Nicola Zomer — Voyage simulator for weather routing under uncertainty](/models/voyage-weather-routing/)
- [Vadim Bertrand — PASTAX: SDE/ODE simulator for ocean-surface drifting trajectories](/models/pastax-ocean-drifters-sde/)
- [Alexandre Loret — Matérn Gaussian Process spatiotemporal simulator (advection / separability)](/models/matern-gaussian-process-matern-spatiotemporal/)
- [Oleksii Kurdysh — SBI integration into di-Higgs search workflow](/models/dihiggs/)
